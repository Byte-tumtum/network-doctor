# Security policy

## Supported versions

Security fixes are released from `main` and shipped in the latest release.
Older releases do not receive separate security updates.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository when it is available, or
email `heymaikol@proton.me` with the subject `network-doctor security`.

Include the affected version and platform, impact, reproduction steps or a
proof of concept, and any suggested mitigation. Avoid including real secrets or
private network data. You will receive an acknowledgement after the report is
reviewed and can coordinate disclosure with the maintainer.
